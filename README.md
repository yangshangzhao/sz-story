## 📖 项目简介

**sz-story** 是一个基于 Claude AI 的深度学习型短故事创作专家系统。采用"先学后写"的创新工作范式，支持节奏紧凑、剧情跌宕起伏、感情张力强、沉浸感浓烈的单篇完结小说创作，自动确保故事连贯性和质量标准。内容题材涵盖现实生活、现言古言、宫斗宅斗、脑洞、悬疑、衍生、历史玄幻等丰富类型。

### 🎯 核心特性

- **智能学习系统**：从参考资料中深度学习写作风格、人设逻辑和世界观设定，支持随机选择单篇参考资料作为主要风格模板
- **纯中文创作**：零容忍非中文内容，确保语言纯度
- **题材丰富多样**：支持现实生活、现言古言、宫斗宅斗、脑洞、悬疑、衍生、历史玄幻等各类题材
- **质量保障体系**：6维质量检查 + 实时纠错机制
- **连贯性保证**：防止内容缺失、设定漂移、人设突变
- **去AI化处理**：5项反检测策略，避免被AI检测工具识别
- **自动化持久化**：智能文件管理，按故事内容自动保存

## 📋 工作流程

### 🔄 新建创作模式

1. **环境扫描** → 验证参考资料目录
2. **深度学习** → 分析参考资料风格，支持随机选择单篇作为模板
3. **内容创作** → 生成高质量内容
4. **自动化持久化** → 智能保存文件

### 🔄 继续创作模式

1. **上下文检索** → 扫描项目目录读取上次内容
2. **上下文学习** → 提取人物、设定、伏笔信息
3. **连贯性保障** → 确保新内容与前文无缝衔接
4. **异常修复** → 自动补齐缺失内容

## 📊 质量标准

### 6维质量检查体系

#### 📖 维度1：故事清晰度与节奏
- ✅ 主线清晰，故事推进明确
- ✅ 节奏紧凑，高潮跌宕起伏，感情张力强
- ✅ 悬念与伏笔合理布局，禁止"只埋不收"

#### 👥 维度2：人设统一性与成长
- ✅ 人物言行符合性格、出身、动机
- ✅ 人物关系合理且动态演变
- ✅ 主角成长弧线完整可信

#### 🌍 维度3：内部自洽性
- ✅ 世界观规则严格遵守
- ✅ 禁止前后矛盾（如"真气耗尽会死"却安然无恙）
- ✅ 特殊机制（如魔法、穿越、科技）逻辑一致

#### 🧠 维度4：角色智商与冲突合理性
- ✅ 反派足够强大聪明，有实质威胁
- ✅ 主角胜利基于努力、智慧而非降智或天降神兵
- ✅ 所有冲突都有合理因果

#### 📝 维度5：基本信息一致性
- ✅ 人物信息统一（眼睛颜色、家庭背景等）
- ✅ 时间线准确（昨天周一，今天不能周三）
- ✅ 地点场景描写一致

#### 🔗 维度6：因果关系合理性
- ✅ 重大转折有充分内在原因和外部推动
- ✅ 人物决定基于当前信息和性格
- ✅ 禁止无原因的立场转变

### 🛡️ 去AI化策略

- ✅ **无效细节**：插入无关琐碎信息
- ✅ **逻辑跳跃**：场景转换偶尔不顺畅
- ✅ **情感毛边**：情感表达不完全、不确定
- ✅ **故意犯规**：打破完美排比，词汇搭配别扭
- ✅ **个人怪癖**：口头禅、非常规审美视角

### 输出文件格式

- **文件名格式**：`[故事名]_[标题].txt` 或 `[故事名]_第X段_[小节标题].txt`
- **纯中文命名**：故事名和标题必须使用纯中文
- **自动序号管理**：确保分段序号或内容顺序连贯

## ⚙️ 技术规格

### 创作参数

| 参数     | 规格             |
| -------- | ---------------- |
| 故事字数 | 6000～80000字    |
| 语言要求 | 纯中文（零容忍） |
| 保存格式 | UTF-8 文本文件   |

### 质量控制

- **实时扫描**：每50字自动检查
- **自动纠错**：发现问题立即修正
- **三重验证**：生成→补齐→保存前验证
- **零容忍政策**：任何质量问题都必须解决才能保存

## 🔧 高级功能

### 内容序号管理

系统采用**绝对零容忍**的顺序管理机制：

```
已有分段：1, 2, 3, 5, 6, 8, 9
↓
缺失检测：发现缺失第4、7段
↓
自动补齐：先生成第4段，再生成第7段
↓
质量验证：每个补齐部分都执行完整检查
↓
连贯确认：全部补齐后重新验证顺序完整
```

### 上下文接续

**继续创作模式**自动执行：
- 📖 扫描项目目录读取上次内容
- 🧠 提取关键信息（人物、设定、伏笔）
- 🔗 确保新内容无缝衔接
- ⚡ 异常修复（补齐缺失内容）

## ⚠️ 注意事项

### 禁止事项

- ❌ **非中文内容**：任何英文、其他语言混入
- ❌ **内容缺失**：不能跳过任何规划的内容
- ❌ **设定漂移**：人物、世界观前后矛盾
- ❌ **AI特征明显**：过度完美、排比、对偶
- ❌ **元叙事评论**：作者声音混入故事
- ❌ **伏笔遗忘**：只埋不收的悬念

### 最佳实践

- 📚 **准备参考资料**：放入 `references/` 目录供学习，系统将随机选择其中一篇作为主要风格参考
- 🔄 **分批创作**：建议一次完成1-3次内容确保连贯
- ✅ **质量确认**：每次保存前仔细检查质量报告
- 📝 **纯中文环境**：确保所有输入输出都是纯中文

## 📈 质量保证

### 验证流程

1. **实时检查**：创作过程中每50字扫描
2. **内容验证**：单个作品完成后质量检查
3. **连贯验证**：多段时检查顺序和设定一致性
4. **保存验证**：最终确认无任何问题

### 错误处理

- **自动纠错**：发现问题立即停止并修正
- **补齐机制**：缺失内容自动生成补齐
- **验证失败**：不符合标准无法保存，必须修复
